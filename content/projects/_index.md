Probably, my most interesting project is [XunilOS](https://git.csd4ni3l.hu/XunilGroup/XunilOS).
It's an OS made from scratch in Rust, using the Limine bootloader.
It has both x86_64 and aarch64 support (aarch64 only works in QEMU), IPC, SHM, syscalls, a [libc stub](https://git.csd4ni3l.hu/XunilGroup/libxunil), [windowing/processes](https://git.csd4ni3l.hu/XunilGroup/xunil-init), and can run [Doom](https://git.csd4ni3l.hu/XunilGroup/doomgeneric-xunil) (obviously).

I've also made several games and experiments in Python with the Arcade & Pyglet game engines. 
Most notably:
- [Fractal Viewer](https://git.csd4ni3l.hu/csd4ni3l/fractal-viewer) which allows you to view lots of fractals and uses a compute shader.
- [Shatterstack](https://git.csd4ni3l.hu/csd4ni3l/shatterstack) which is a pretty fun game which is similar to Tetris (Warning: I don't own the Tetris trademark).
- [Browser](https://git.csd4ni3l.hu/csd4ni3l/browser) which is a browser written from scratch, following the [browser.engineering tutorial](https://browser.engineering/), which I've not yet rewritten in Rust.
- [Simulator Games](https://git.csd4ni3l.hu/csd4ni3l/simulator-games) which includes lots of interesting games/simulations like boids, double pendulum, Fourier, and more.
- [gp-dl](https://git.csd4ni3l.hu/csd4ni3l/gp-dl) which allows you to download Google Photos albums with no interaction in a headless environment using Selenium.
- [game-of-life](https://git.csd4ni3l.hu/csd4ni3l/game-of-life) which is Game of Life written in Python, running inside blazingly fast compute shaders.

I've also made a [soundboard](https://git.csd4ni3l.hu/csd4ni3l/soundboard) in Rust and I'm always trying to make new stuff!
